About

Working at the edge of structure and noise.

I build abstract visual work exploring how order emerges from chaos — gradients, particle fields, and geometric systems rendered as both still frames and motion pieces. Every piece here is stored, tagged, and served through a small self-built archive.

Process

Each piece begins as a system — a noise field, an attractor, a rule set — before it becomes an image. The archive on this page is powered by a small Node/Express API backed by SQLite, so new work can be pushed straight from the admin panel and appears here instantly.
